# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in all project spaces and for anyone representing the project elsewhere.

MIDB exists to make sexual violence and misogyny in films visible to the people who need to avoid or discuss them. Contributions and discussions keep survivors at the centre: no mocking, minimising or denying sexual violence, no harassment, no slurs, no sexualised language, no personal attacks. Criticise the work, not the person.

## Reporting

Report privately to the maintainers, through the Security tab ("Report a vulnerability" opens a private thread) or a direct message on GitHub. Reports are confidential. The maintainers may remove, edit or reject contributions that break this code, and may ban a contributor temporarily or permanently, following the Contributor Covenant's enforcement guidelines.
